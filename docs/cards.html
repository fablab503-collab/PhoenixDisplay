WHAT THIS ONE DOES THAT IS UNUSUAL

Real 5120 × 2880, not upscaled
H.264 hardware encoding stops at 4096×2304. HEVC does not — so it uses HEVC, and says so.
HEVC
Tells you if the link can carry it
Live link speed per interface, judged on peak not average. Options your cable cannot carry are dimmed.
LIVE
Wi-Fi, Ethernet or Thunderbolt — recognised and pinnable
Thunderbolt 3 and 4 told apart by negotiated rate. Automatic shows which route it actually chose.
AUTO
Runs with no window at all
Lives in the menu bar. Start with nothing on screen and it advertises immediately.

WHAT IT DOES

Mirror or extend
Extend creates a genuine second desktop you can drag windows onto, placed left, right, above or below
✓
Make it the main display
Moves the menu bar to the streamed screen, and puts it back
✓
Works with older builds
The receiver announces what it can decode; a build that announces nothing still gets H.264
✓

WHAT IT DOES NOT DO — STATED PLAINLY

Not for fast pointer work
A streamed screen has compression latency. Good for reference, documentation, chat, monitoring. Not a cabled monitor.
LATENCY
The 5K desktop runs at 1×
setHiDPI: yields no Retina mode on macOS 27. Pixel-perfect, but interface elements are physically small.
NO 2×
An extra desktop lives until the app quits
Releasing the display object deallocates it — verified — but the window server keeps it registered.
KNOWN
macOS 13 minimum
Rules out iMac 2012, 2013, 2014 and 2015 outright. 2017 and later only.
2017+
Not on the Mac App Store
Extend mode uses private CoreGraphics API. Guideline 2.5.1 forbids it, and hiding it from review is not an option worth taking.
BY DESIGN
Every number in these cards came from running the thing. Where something was not tested — whether macOS stays awake with the lid closed on a virtual display — it says so instead of guessing.
